## قوانین وزارت معارف پیاده‌شده

- **سطوح:** صنف ۱–۶ ابتدائیه، ۷–۹ متوسطه، ۱۰–۱۲ لیسه
- **امتحانات سال تعلیمی ۱۴۰۵:** امتحان چهارونیم‌ماهه (۴۰ نمره) + امتحان سالانه (۶۰ نمره) = ۱۰۰ نمره سالانه هر مضمون (طرزالعمل امتحانات ۱۴۰۵ وزارت معارف)
- **نمره قبولی:** ۴۰ فیصد در هر مضمون؛ **شرط ارتقا:** میانگین کلی حداقل ۵۵ فیصد
- **درجه‌بندی:** ۸۶–۱۰۰ عالی، ۶۶–۸۵ خوب، ۴۰–۶۵ قابل، زیر ۴۰ مردود
- **ارتقا:** صنف ۱–۳ ارتقای توصیفی؛ صنف ۴–۱۲: ارتقا / ارتقا مشروط (حداکثر ۲ مضمون مردود) / تکرار صنف — با مقام اول تا سوم هر صنف
- **سال تعلیمی:** آغاز ۶ حمل (مناطق سردسیر) — تقویم هجری شمسی با نام‌گذاری Afghan (حمل تا حوت)
- **مراجع:** [لوایح وزارت معارف](http://moe.gov.af/dr/لوایح) — لایحه درجه‌بندی شاگردان، لایحه شورای مکتب، لایحه نامگزاری موسسات تعلیمی معارف، لایحه نظارت تعلیمی تعلیمات عمومی، لایحه کورس‌های تعلیمی خصوصی؛ و [سیستم نمره‌دهی افغانستان](https://www.afghanistaneducation.info/education-system/grading-system.html) (قبولی ۴۰٪ و میانگین ارتقا ۵۵٪)
- تمام اعداد فوق از صفحه تنظیمات قابل تغییر اند.

## نصب و اجرا

```bash
bun install
bun run db:generate
bun run db:push        # دیتابیس SQLite در db/custom.db
bun prisma/seed.ts     # معلومات نمونه (مکتب، ۴۳ متعلم، ۱۰ کارمند، فیس، امتحانات…)
bun run dev            # http://localhost:3000
```

## پیام‌رسانی (SMS)

در «تنظیمات → قوانین معارف» آدرس دروازه پیام (smsGatewayUrl)، کلید (smsApiKey) و نام فرستنده را وارد کنید؛ سیستم پیام‌ها را POST JSON `{phone, message}` ارسال می‌کند. در غیاب دروازه، پیام‌ها در «صف» ذخیره شده و لیست شماره‌ها به شکل CSV قابل خروجی است.

## بیکپ (نسخه احتیاطی)

تنظیمات → بیکپ: دانلود JSON کامل تمام جدول‌ها. برای بیکپ فیزیکی، فایل `db/custom.db` را کپی کنید.

## English (short)

Complete school management system for Afghan private schools (grades 1–12): student records per Ministry of Education forms (triplicate registration, biography card, ID card), daily & monthly attendance, staff management, fees with printable receipts and owner handovers, exams (40+60 marks per MoE 1405 regulation) with auto result sheets, report cards and notifications, treasury with income/expense/withdrawal ledger, monthly profit & loss, transport, book & uniform sales, parent SMS messaging (pluggable gateway), Dari/Pashto/English UI with Solar Hijri calendar, role-based access (5 roles), JSON backup.
